# 🛒 E-Commerce Sales Analysis Using SQL

## 📌 Project Overview

This project focuses on analyzing an **E-commerce sales database** using **MySQL** to extract meaningful business insights and support data-driven decision-making.

The project contains **350+ SQL queries** covering basic to advanced SQL concepts, including filtering, aggregation, joins, subqueries, CTEs, and window functions.

---

## 🎯 Project Objectives

* Analyze customer and sales data.
* Understand product and category performance.
* Evaluate orders, payments, and shipping activities.
* Identify valuable business insights using SQL.
* Practice and demonstrate intermediate-to-advanced SQL skills.
* Perform data-driven analysis using a relational database.

---

## 🗄️ Database Structure

The project contains **8 interconnected tables**:

| Table         | Description                       |
| ------------- | --------------------------------- |
| `customers`   | Customer information              |
| `products`    | Product details and pricing       |
| `categories`  | Product category information      |
| `brands`      | Brand information                 |
| `orders`      | Customer order records            |
| `order_items` | Products included in each order   |
| `payments`    | Payment details and status        |
| `shipping`    | Shipping and delivery information |

## 🚀 How to Run the Project

### 1. Install MySQL

Install **MySQL Server** and **MySQL Workbench**.

### 2. Create the Database

Run the database creation script:

```sql
CREATE DATABASE ecommerce_db;

USE ecommerce_db;
```

### 3. Create Tables

Execute the table creation queries in the database setup file.

### 4. Insert Data

Run the insert-data SQL file to populate the tables.

### 5. Execute Analysis Queries

Open the individual SQL files and execute the queries in **MySQL Workbench**.

> **Note:** Execute the database creation and data insertion scripts before running the analysis queries.
